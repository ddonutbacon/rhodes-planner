# Acknowledgements

Rhodes Planner would not exist without the work of the Arknights community and the open-source projects that make tools like this possible.

A sincere thank you to:

- **Hypergryph and Yostar** for creating and publishing *Arknights*, the game that inspired this project.
- [**ArknightsAssets / ArknightsGamedata**](https://github.com/ArknightsAssets/ArknightsGamedata) for maintaining accessible structured game data used for operator, material, module, stage and progression planning.
- [**Penguin Statistics**](https://penguin-stats.io/) and [**ArkPlanner**](https://github.com/penguin-statistics/ArkPlanner) for community-maintained drop statistics, farming-planner concepts and interoperability.
- [**ArkPRTS**](https://github.com/ashleney/ArkPRTS) and [**arkprtserver**](https://github.com/ashleney/arkprtserver) for the account-export ecosystem that makes account-aware planning possible without Rhodes Planner handling game credentials.
- [**imivi's Arknights Pulls Calculator**](https://imivi.github.io/arknights-pulls-calculator/) as the recommended external companion tool for pull-resource forecasting. Rhodes Planner v0.7.3 intentionally does not embed a pull calculator. Source: https://github.com/imivi/arknights-pulls-calculator
- [**Arknights Terra Wiki**](https://arknights.wiki.gg/) for community English terminology used as display aliases when future CN-only materials do not yet have official EN game-data localization.
- [**Arknight-Images by Aceship**](https://github.com/Aceship/Arknight-Images), [**PuppiizSunniiz/Arknight-Images**](https://github.com/PuppiizSunniiz/Arknight-Images), and other community maintainers who keep useful visual assets accessible.
- The broader **Arknights community**, whose guides, testing, data collection, documentation and shared knowledge make projects like this possible.
- The maintainers and contributors behind [**Python**](https://www.python.org/), [**Streamlit**](https://streamlit.io/), and the open-source libraries used throughout this project.
- **OpenAI's ChatGPT** for serving as the primary AI-assisted development partner during prototyping, implementation, debugging, refactoring, testing and iteration.

Rhodes Planner was developed through an **AI-assisted development workflow**. Product direction, requirements, validation, UX decisions, testing scenarios, privacy/security decisions and release decisions were directed and reviewed by the project author.

This project is an **unofficial, non-commercial fan project**. All Arknights-related names, characters, artwork, game data and other intellectual property belong to their respective rights holders.

To everyone whose work, data, documentation, tooling and community knowledge helped make Rhodes Planner possible: **thank you.**
