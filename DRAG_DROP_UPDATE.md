# Rhodes Planner v0.7.3 drag-and-drop update

Copy the contents of this package over your existing Rhodes Planner folder and choose **Replace files in the destination**.

The root folder may have any name. For example, `Rhodes Planner`, `portable`, or `Arknights Tools` are all valid. You may also move the complete folder to another drive after the update.

Keep your existing `runtime/` folder unless you are installing a complete portable release that already includes one. This patch does not require a different Python runtime.

Do not move individual internal folders such as `app/`, `rhodes/`, `.streamlit/`, or `runtime/` away from the launcher. Rename or move the **whole application folder** instead.

After copying, start `Rhodes Planner.bat`. Your existing profile remains stored outside the application folder and is not removed by renaming, moving, or replacing application files.
